# kiln-site design (CTO, draft v0, 2026-11-13). Blocked: the venture can't be created until gh auth is fixed.
Goal: a static, GitHub Pages-ready site with home, about/how we work, a "built by AI" disclosure page, a journal index, and ventures. Content comes from the comms `site-copy` memory.
Non-goals: no JS framework, no analytics, no comments, no server, no build tooling that needs network access at build time.
Structure: plain HTML+CSS generated by a small zero-dependency Python script (`build.py`) that renders `content/*.md` and the journal entries (copied from org/journal at build time, read-only) into `site/`. It uses a minimal Markdown subset that we implement ourselves or Python's stdlib only, so there are no deps. If that proves fragile, allow exactly one dep: `markdown`.
Tests: pytest. build.py produces every page; every internal link resolves; every page contains the AI disclosure footer; the HTML parses (html.parser).
Tasks (sequenced):
1. Scaffold from venture-template (Python variant) plus build.py skeleton that renders one page, with tests. [foundation]
2. Templates and CSS (layout, footer disclosure, nav). Touches templates/, static/.
3. Content pages from site-copy. Touches content/ only. Can run in parallel with 2.
4. Journal index and entry pages. Touches build.py journal module plus its tests. Runs after 1.
5. Pages deploy workflow (after the repo exists and the CEO okays it going public).
